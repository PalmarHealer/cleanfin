# goodFin

A Jellyfin theme based on [NeutralFin](https://github.com/KartoffelChipss/NeutralFin) by [KartoffelChipss](https://github.com/KartoffelChipss).

## Usage

Add one of the following to your Jellyfin custom CSS:

```css
@import url('https://cdn.jsdelivr.net/gh/PalmarHealer/goodfin@main/style.min.css');
```

or the unminified version:

```css
@import url('https://cdn.jsdelivr.net/gh/PalmarHealer/goodfin@main/style.css');
```

## Structure

- `src/` — Each change lives in its own `.scss` file. Files are prefixed with a number so they concatenate in a defined order (`000-imports.scss` and `001-root.scss` come first).
- `style.css` / `style.min.css` — Built artifacts in the repo root. **Do not edit these by hand** — they are regenerated by the build action.

## Build

A GitHub Action (`.github/workflows/build.yml`) concatenates `src/*.scss` in sorted order and compiles them with Dart Sass into:

- `style.css` — expanded
- `style.min.css` — compressed

The action runs on every push that touches `src/**` and commits the rebuilt CSS back to `main`.

To build locally:

```bash
npm install -g sass
cat src/*.scss > _bundle.scss
sass --style=expanded _bundle.scss style.css
sass --style=compressed _bundle.scss style.min.css
```
